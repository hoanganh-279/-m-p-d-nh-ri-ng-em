# Trái tim kỷ niệm — Bé Tẹt · 20/10

Website tương tác 3D (React + Vite + React Three Fiber) nhân ngày 20/10.

## Chạy local

```bash
npm install
npm run optimize-images   # lần đầu / khi thêm ảnh mới vào img/
npm run dev
```

Mở `http://localhost:5173`.

## Nhạc nền

Đặt file MP3 vào `public/audio/` với tên:

- `cho-chut.mp3`
- `em-be-thom.mp3`
- `nang-am-trong-tim.mp3`
- `comethru.mp3`
- `a-thousand-years.mp3`
- `a-little-love.mp3`
- `baby.mp3`

Không tự phát nhạc trước khi người dùng bật.

## Sửa chú thích ảnh

Chỉnh `src/data/memories.ts` (caption / date).

## Build

```bash
npm run build
npm run preview
```
